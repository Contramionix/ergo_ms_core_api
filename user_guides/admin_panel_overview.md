# Админ-панель (обзор)

Разделы админ-панели видят **администраторы** и пользователи с соответствующими правами. Обычному пользователю эти пункты в меню не показываются.

## Типичные разделы

| Раздел | Для чего |
|--------|----------|
| **Пользователи** | учётные записи, роли, пароли, сессии |
| **Роли и права** | что можно делать в модулях и разделах |
| **Меню** | структура бокового меню сайта |
| **Аудит** | журнал действий (кто что менял) |
| **Приглашения** | ссылки для самостоятельной регистрации (если включено) |

## С чего начать администратору

1. Создайте или найдите пользователя в **Пользователях**.
2. Назначьте **роль** с нужными правами на модули.
3. Проверьте, что нужные пункты есть в **Меню** и видны после повторного входа пользователя.
4. При разборе инцидентов смотрите **Аудит**.

Подробнее про пользователей и роли — в справке «Пользователи, роли и доступ».
