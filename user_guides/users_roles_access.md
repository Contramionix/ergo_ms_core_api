# Пользователи, роли и доступ

Эти разделы доступны **администраторам** (или пользователям с соответствующими правами). Обычный пользователь их в меню не видит.

## Пользователи

В **Админ-панели → Пользователи** можно:

- просматривать список учётных записей;
- создавать пользователя (логин, пароль или автогенерация, email);
- назначать роль и группы;
- приостанавливать вход, сбрасывать пароль, завершать сессии;
- открывать настройки конкретного пользователя.

## Роли и права

- **Роль** определяет, какие разделы и действия доступны в системе.
- **Ролевые группы** объединяют роли для удобного назначения.
- Права на модули (например, просмотр AI-ассистента) выдаются через каталог прав модуля.

## Как выдать доступ к разделу

1. Убедитесь, что нужный модуль установлен в системе.
2. Назначьте пользователю роль с нужными правами (или добавьте право на модуль).
3. Проверьте, что пункт появился в боковом меню у этого пользователя после повторного входа или обновления страницы.

## Приглашения

Если в меню есть **Приглашения**, можно отправить ссылку для самостоятельной регистрации по правилам организации.

Общий обзор разделов для администратора — в справке «Админ-панель (обзор)».
