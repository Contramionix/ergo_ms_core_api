# Уведомления

## Где найти

В **шапке** справа есть значок **колокольчика**. На нём может отображаться число непрочитанных уведомлений.

## Как пользоваться

1. Откройте колокольчик в шапке.
2. Просмотрите список уведомлений — новые обычно выделены.
3. Откройте нужное уведомление, чтобы перейти к связанному разделу (если ссылка есть).
4. При необходимости отметьте уведомления как прочитанные.

## Настройка

Типы и каналы уведомлений настраиваются в **меню пользователя → «Настройки» → вкладка «Уведомления»**.

Если уведомлений нет или колокольчик пуст — либо событий ещё не было, либо для вашей роли они отключены. Спросите у администратора, какие события включены в организации.
